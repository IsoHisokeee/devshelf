### 1. Overview & Core Concept

- **Что представляет собой DevShelf**: Автономный настольный и мобильный инструмент веб-разработчика, объединяющий исчерпывающий русскоязычный справочник по стандартам веб-платформы, интерактивные визуальные генераторы (Flex/Grid/Shadows) и песочницу с живым выполнением кода.
- **Главный приоритет**: Максимальная практическая польза. Разработчик должен за 2 секунды находить точный синтаксис или рецепт (например, «как отцентрировать элемент», «pdo prepared statement», «dialog showModal с фокусом», «container query»), копировать готовый сниппет и при желании сразу тестировать его в живом окне.
- **Автономность**: Все 200+ справочников и генераторы встроены в бандл и кэшируются через Service Worker, работая на 100% без подключения к интернету.

#### Эстетические принципы (Anti-AI-Slop):
- **Цветовая палитра**:
  - Холст: темный матовый обсидиан (`#0b0f17`), вспомогательные панели (`#111726`), фон кода (`#080c14`).
  - Линии и границы: строгие тонкие рамки `1px solid rgba(255,255,255,0.08)` (в светлой теме: `#e2e8f0`).
  - Акценты: функциональный синий код (`#38bdf8` / `#2563eb`) строго для интерактивных элементов, янтарный (`#f59e0b`) для избранного, изумрудный (`#10b981`) для обратной связи успешного копирования. Никакого случайного фиолетово-розового градиента.
- **Типографика**:
  - Дисплейный шрифт: `Plus Jakarta Sans` / `Inter Display` (чёткие линии, строгий кернинг).
  - Моноширинный шрифт: `JetBrains Mono` с активированным `tabular-nums` для цифр, атрибутов и блоков кода.
- **Zero-Pill Discipline**:
  - Никаких овальных цветных плашек для тегов и категорий. Метаданные пишутся чистым шрифтом: `HTML · Формы · Семантика · 2 мин чтения`.
  - Кнопки имеют аккуратный радиус 6px (`rounded-md`), строгую геометрию и понятные подписи действий («Копировать», «Сбросить», «В песочницу»).

### 3. Наполнение русскоязычной базы (80–90% охват веб-стека)

База структурируется по 5 фундаментальным модулям (200+ тем):

1. **HTML5 & Web Semantics (45+ тем)**:
   - Базовая структура, метаданные, OpenGraph, Twitter Cards, Schema.org JSON-LD.
   - Семантические контейнеры: `<header>`, `<main>`, `<article>`, `<section>`, `<nav>`, `<aside>`, `<footer>`.
   - Интерактивные элементы: `<dialog>` (модальный режим, `showModal()`, `close()`), `<details>`/`<summary>`, `<template>`, `<slot>`.
   - Формы и элементы ввода: все типы `<input>`, `<textarea>`, `<select>`, `<datalist>`, атрибуты валидации (`pattern`, `required`, `min/max`).
   - Медиа и графика: `<picture>` с `srcset` и `sizes`, `<video>`, `<audio>`, `<canvas>`, `<svg>` инлайн.
   - Доступность: атрибуты `aria-*`, роли `role`, доступный фокус `tabindex`.

2. **Современный CSS (60+ тем)**:
   - Flexbox: контейнер (`display: flex`, `flex-direction`, `justify-content`, `align-items`, `gap`, `flex-wrap`) и элементы (`flex-grow`, `flex-shrink`, `flex-basis`, `align-self`, `order`).
   - CSS Grid: `grid-template-columns` (`fr`, `repeat()`, `minmax()`), `grid-template-areas`, `gap`, `auto-fit` vs `auto-fill`, `subgrid`.
   - Новые возможности CSS: `@container` (Container Queries), селекторы `:has()`, `:is()`, `:where()`, `:not()`, вложенность CSS Nesting (`&`).
   - Позиционирование: `relative`, `absolute`, `fixed`, `sticky` с нюансами родительского скролла.
   - Переменные и функции: `var()`, `@property`, математические функции `calc()`, `min()`, `max()`, `clamp()`.
   - Цвета и эффекты: `oklch()`, `color-mix()`, `box-shadow`, `backdrop-filter` (стекло), градиенты, `@keyframes` и переходы `transition`.

3. **JavaScript & Web APIs (55+ тем)**:
   - DOM: `querySelector`, `querySelectorAll`, `closest`, `matches`, манипуляция классами и атрибутами (`dataset`).
   - События: `addEventListener`, делегирование событий через контейнер, `event.preventDefault()`, `event.stopPropagation()`, кастомные события `CustomEvent`.
   - Асинхронность: `fetch` (GET/POST/JSON), обработка ошибок с `try/catch`, отмена запросов через `AbortController`, `Promise.all` / `Promise.allSettled`.
   - Современные Web APIs: `IntersectionObserver` (ленивая загрузка картинок, появление при скролле), `ResizeObserver`, Clipboard API (`navigator.clipboard.writeText`), LocalStorage и SessionStorage.
   - Массивы и объекты: `map`, `filter`, `reduce`, `find`, `some`, `every`, `flatMap`, `structuredClone`, деструктуризация, Spread-оператор, `Optional Chaining` (`?.`), `Nullish Coalescing` (`??`).

4. **Современный PHP 8.x & Backend (30+ тем)**:
   - PDO: безопасное подключение с обработкой ошибок (`PDO::ATTR_ERRMODE`), Prepared Statements (`prepare` + `execute`), выборка (`fetch`, `fetchAll`, `PDO::FETCH_ASSOC`), транзакции (`beginTransaction`, `commit`, `rollBack`).
   - Синтаксис PHP 8: nullsafe operator (`?->`), выражение `match`, union types, constructor promotion, именованные аргументы.
   - Работа с API и JSON: `json_encode`, `json_decode`, установка заголовков `header('Content-Type: application/json')`.
   - Сессии и аутентификация: `session_start()`, безопасные куки (`HttpOnly`, `SameSite`, `Secure`), хеширование паролей (`password_hash`, `password_verify`).
   - Работа с файлами и формами: валидация загрузки файлов `$_FILES`, `file_get_contents`, `file_put_contents`, регулярные выражения `preg_match`.

5. **XML, SVG & Архитектура сайтов (15+ тем)**:
   - Синтаксис XML: пролог, сущности, CDATA, пространства имен `xmlns`.
   - Поисковые форматы: создание валидного `sitemap.xml` (с датами и приоритетами), создание `robots.txt` и `robots.xml`.
   - RSS / Atom ленты: структура фида новостей и статей.
   - SVG разметка: `viewBox`, примитивы `<path>`, `<circle>`, оптимизация и экспорт.

### 4. Интерактивная мастерская (Генераторы & Шаблоны)

1. **Визуальный конфигуратор Flexbox**:
   - Панель управления направлением (`row`, `column`), выравниванием по главной и поперечной осям, отступами (`gap`).
   - Живой интерактивный контейнер с перетаскиваемыми или добавляемыми блоками.
   - Мгновенная генерация чистого CSS-кода с кнопкой «Копировать» и «Открыть в Playground».

2. **Визуальный построитель CSS Grid**:
   - Настройка колонок и строк ползунками (`1fr 2fr 1fr`, `repeat(auto-fit, minmax(200px, 1fr))`).
   - Предпросмотр адаптивной сетки при изменении ширины контейнера.

3. **Генератор теней и матового стекла (Shadow & Glass)**:
   - Слайдеры для смещения, размытия, цвета, прозрачности и `backdrop-filter: blur()`.
   - Готовый CSS с кросс-браузерными префиксами.

4. **Интерактивные шаблоны компонентов**:
   - Бургер-меню (адаптивная кнопка + выезжающая шторка, с доступностью по Esc и блокировкой скролла).
   - Модальное окно (на основе нативного `<dialog>` с правильным фокусом и backdrop).
   - Аккордеон (FAQ с плавным раскрытием).
   - Вкладки (доступные табы с клавиатурной навигацией).

### 5. Офлайн PWA и Персональное хранилище

1. **PWA Спецификация**:
   - Модуль `vite-plugin-pwa` в `vite.config.js`.
   - Полноценный `manifest.json` с иконками 192x192, 512x512 и maskable.
   - Метатеги Apple Touch Icon и mobile-web-app-capable.
   - Кнопка установки `PWAInstallButton` в навигации и индикатор офлайн-статуса при обрыве сети.

2. **Персональное избранное и экспорт**:
   - Сохранение закладок в `localStorage`.
   - Фильтр «★ Избранное» в главном списке.
   - Экспорт любого сниппета или кода песочницы в один клик (копирование в буфер с приятным тостом / скачивание готового `.html` файла).
