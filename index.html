Выбор инструмента: нативный стек или фреймворк

Когда достаточно чистого HTML/CSS/JS, а когда стоит подключить современный фреймворк.

Чистый CSS3 vs Tailwind CSS v4

Нативный CSS сегодня умеет переменные, вложенность и :has(). Но если нужно собирать десятки экранов без придумывания названий классов — подключите Tailwind CSS через Vite или CDN.

Vanilla JS vs Alpine.js / HTMX

Для простых сайтов на PHP или WordPress не нужен тяжёлый сборщик: 1 строка подключения Alpine.js (15 КБ) или HTMX заменяет сотни строк ручного querySelector и fetch.

SPA и SSR: React 19 / Vue 3 / Next.js

Для личных кабинетов, дашбордов и SaaS со сложным состоянием выбирайте компонентный подход (React 19 или Vue 3 в связке со сборщиком Vite и типизацией TypeScript).

Процедурный PHP vs Laravel 11

Для одного обработчика формы достаточно чистого PHP 8.3 с PDO. Для проекта с авторизацией, ролями, очередями и миграциями БД стандартом де-факто является Laravel.

Чек-листы перед публикацией проекта

Быстрая самопроверка качества вёрстки, безопасности и SEO.

HTML, SEO и метаданные

  • Заполнены уникальные <title>, meta description и Open Graph.
  • У всех картинок указаны alt, width и height (без скачков CLS).
  • Настроены robots.txt, sitemap.xml и канонические ссылки.

Адаптивность (Mobile / Tablet / Desktop)

  • Нет горизонтального скролла на экранах 320px–375px (iPhone SE / Android).
  • Модальные окна и таблицы корректно прокручиваются на планшетах и ноутбуках.
  • Сохранены видимые контуры фокуса :focus-visible для клавиатуры.

JavaScript и безопасность PHP

  • Все сетевые вызовы fetch обёрнуты в try / catch со статусами загрузки.
  • SQL-запросы выполняются только через подготовленные выражения PDO::prepare.
  • Пароли хешируются через password_hash(), а вывод экранируется от XSS.
